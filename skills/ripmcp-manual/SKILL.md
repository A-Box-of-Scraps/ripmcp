# `ripmcp`

Manage and invoke MCP servers from the shell.

**Usage:**

Explore the manual and command help as needed. Replace `PATTERN` and `COMMAND` as appropriate:

```sh
man -P cat ripmcp
man -P cat ripmcp | rg -n -e 'PATTERN'
ripmcp --help
ripmcp COMMAND --help
```

**When to use:** Install and manage MCP servers, and discover and invoke their tools.
